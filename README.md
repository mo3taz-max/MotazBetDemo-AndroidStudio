# Motaz Bet Demo (Android)

مشروع Android Studio بسيط لواجهة توقعات رياضية تجريبية فقط.

## ما الذي يحتويه؟
- واجهة داكنة بالأسود والذهبي.
- مباريات افتراضية.
- صفحة نموذج طلب تجريبي تعرض رقمًا كنص قابل للنسخ.
- لوحة مسؤول محلية تعرض الطلبات التي أُنشئت في الجلسة الحالية.

## قيود مهمة
- هذا نموذج واجهة فقط، وليس منصة مراهنات مالية.
- لا ينفّذ تحويلات أو يتحقق من الإيداعات.
- لا يرفع صورًا ولا يخزّن الطلبات بعد إغلاق التطبيق.
- لوحة المسؤول ليست محمية بتسجيل دخول؛ لا تستخدمها مع بيانات حقيقية.
- لا تستخدم بيانات شخصية أو إثباتات تحويل حقيقية في هذا النموذج.

## فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `MotazBetDemo` من Android Studio.
3. وافق على مزامنة Gradle.
4. من القائمة: Build > Build Bundle(s) / APK(s) > Build APK(s).

قد يحتاج Android Studio إلى تنزيل Gradle وAndroid SDK المناسبين أول مرة.
